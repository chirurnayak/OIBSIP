# OIBSIP – Java Development Internship

This repository contains the projects and tasks completed as part of my **Java Development Internship at Oasis Infobyte (OIBSIP)**.

## 👨‍💻 About the Internship

The internship focuses on developing practical Java programming skills through hands-on projects involving **Object-Oriented Programming, database connectivity, and application development**.

## 🛠️ Technologies Used

* **Java 21**
* **Maven**
* **SQLite**
* **JDBC**
* **Git & GitHub**
* **VS Code**

## 📂 Projects

### Task 1 – Online Reservation System

A Java-based reservation system that allows users to log in, make reservations, and cancel reservations using a PNR number.

**Features:**

* User Login
* Reservation/Booking
* PNR Generation
* Reservation Details
* Cancellation using PNR
* SQLite database integration
* JDBC connectivity

📁 Folder: `JavaDevelopment-Task1-OnlineReservationSystem`

---

### Task 3 – ATM Interface

A console-based ATM application developed using Java and Object-Oriented Programming concepts.

**Features:**

* User ID and PIN authentication
* Maximum 3 login attempts
* Check account balance
* Withdraw money
* Deposit money
* Transfer money
* Transaction history
* Exit/Logout

📁 Folder: `JavaDevelopment-Task3-ATMInterface`
